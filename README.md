Rust:

To use your own input you can:

- Put an input.txt in the directory (year/day_xx/). Then you can build and run the project using cargo.
- You can pass the file path of the .txt into the program as a command line argument.



C# (Only 24/25):

If you want to add an input:
After building the project, create an Input.txt with your input in the output directory (i.e. Day-07\bin\Debug\net8.0
